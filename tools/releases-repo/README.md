# RIOSV Imports — издания

Тук стоят изданията на **RIOSV Imports** — програмата за отчетите към НИСО — и
новините, които тя показва на началния си екран. Кодът на програмата не е тук.

## Инсталиране

1. Отворете [последното издание](https://github.com/mugen89/RiosvImports-releases/releases/latest).
2. Изтеглете `RiosvImports-win-Setup.exe` и го пуснете.

Програмата се инсталира в профила ви и не иска права на администратор.
Работата ви стои в `%LOCALAPPDATA%\RIOSV Imports` и не се пипа нито от
обновяването, нито от премахването на програмата.

Без инсталиране: `RiosvImports-win-Portable.zip` от същото място. И тя се
обновява сама.

## Обновяване

Програмата пита тук при всяко пускане. Новото издание излиза на началния
екран заедно с бележките си и се слага с копче — програмата никога не се сменя
сама. Проверката се изключва от „Настройки → Обновяване“.

Пробните издания (`v1.4.0-beta.1` и подобни) стигат само до програмите, в
които е вдигнато „Предлагай и пробните издания“.

## Новините

`news.json` е файлът, който програмата чете при пускане. Пише се на ръка,
направо в GitHub, и стига до всички при следващото им пускане.

```json
{
  "news": [
    {
      "id": "2027-03-01-srok",
      "date": "2027-03-01",
      "severity": "important",
      "title": "Срокът за годишните отчети е 31 март",
      "body": "Годишните отчети се подават в НИСО подписани с КЕП.",
      "link": "https://...",
      "until": "2027-03-31"
    }
  ]
}
```

| Поле | |
|---|---|
| `id` | Белегът. Не се сменя — сменен, съобщението излиза като ново и у тези, които вече са го прочели. |
| `date` | `гггг-мм-дд`. По нея се подреждат съобщенията. |
| `severity` | `info`; `important` — оцветено; `critical` — изскача веднъж при пускане. |
| `title`, `body` | Заглавие и текст. Без Markdown — показват се както са написани. |
| `link` | По избор. Само `https://` — „Прочети още“ води там. |
| `until` | По избор: след тази дата съобщението не се показва. |
| `from`, `below` | По избор: само за издание от … нагоре / под …. Например `"below": "1.3.1"` стига само до тези, които още не са обновили. |

Поправеният текст на вече прочетено съобщение не го прави ново. Махнатото от
файла изчезва и от програмата. Повреден файл не пипа нищо — програмата
показва последните новини, които е прочела.
